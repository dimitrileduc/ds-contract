# Rapport — soirée du 22 juillet 2026

**Question de départ :** est-ce que le dashboard et le dépôt fonctionnent
vis-à-vis du Figma Piqueray, pour qu'on voie les vrais écarts ?

**Réponse : oui maintenant. Ce n'était pas le cas ce matin.**

---

## 1. Ce qui ne marchait pas, et qu'on ne voyait pas

Le dashboard affichait **« Parity — Clean · 51 contrats vérifiés · 0 écart »**.

Trois mensonges empilés :

1. Les 51 contrats avaient été **supprimés** le matin même.
2. La comparaison se faisait contre une photo de **l'ancien fichier Figma de démo**
   (`8nim1d0IPnehMxA7B7SYxC`), pas contre Piqueray (`d9FYAUcqdcNtsuaMgLefvJ`).
3. « Clean » était donc un verdict **sur le mauvais fichier**.

Rien ne signalait qu'un rapport était périmé. C'est la classe de bug la plus
grave dans ce dépôt : une omission silencieuse.

---

## 2. Ce qui a été fait

### Le dashboard dit la vérité

| | Avant | Après |
|---|---|---|
| Composants listés | 0 puis 51 fantômes | **1** — le Button, avec son rendu réel |
| Fichier Figma comparé | l'ancien fichier de démo | **le tien** |
| Écarts affichés | « 0 » (faux) | **47**, tous vrais, chacun avec son remède |
| Tuile « Adherence 100 vs 69 » | affichée comme stat Piqueray | **archivée** |
| Sections vitrine | 2, démo-era, non signalées | **archivées** avec notice |

### Le comparateur réparé — deux vrais bugs

**Bug 1 — noms de collection codés en dur.** `parity/diff.ts` supposait que la
collection Figma s'appelle `Primitives` avec un mode `Value`. Un fichier que le
dépôt n'a pas généré lui-même (le tien) nomme les choses autrement. Résultat :
**14 variables bien présentes étaient déclarées absentes**. Le comparateur sait
maintenant faire le pont — et il **l'annonce à l'écran**, parce qu'un
rapprochement silencieux serait pire que le bug d'origine.

**Bug 2 — la transparence jetée.** `parity/extract-figma.plugin.js` ne lisait que
le rouge/vert/bleu d'une couleur, jamais l'opacité. Tes trois variables
translucides (`beige-clair-80`, `orange-12`, `orange-42`) étaient donc lues comme
opaques, ce qui **inventait 3 désaccords de valeur inexistants**.

**60 écarts → 47.** Les 13 disparus n'étaient pas des écarts : c'était
l'instrument qui mesurait mal.

### Les tests remis d'aplomb

| | |
|---|---|
| Avant | 50/147 |
| Après | **93 passent sur 96 exécutés** |
| Gelés | **51**, code préservé **à l'identique** (vérifié ligne à ligne) |
| Rouges **exprès** | **3** |

Les 51 gelés vivent dans `evals/legacy-cases.ts`, réactivables par un simple
déplacement. `evals/REMOVED-CASES.md` les classe **par ce qu'il faudrait que
Piqueray gagne** pour les réveiller : un 2ᵉ composant, un composant composé, un
slot, des états d'interaction, une 2ᵉ marque. C'est ta liste de courses.

La quarantaine s'imprime **à chaque run**, pour que 93/96 ne puisse jamais passer
pour une victoire complète.

**Les 3 rouges assumés** — `baseline-parity-clean`,
`baseline-acknowledges-without-failing`, `promotion-converges` — exigent une
comparaison Figma parfaitement propre. Impossible tant que Figma n'a pas reçu
tes valeurs. Les geler ou les déclarer « acceptés » aurait été un mensonge.

### Migration mono-thème terminée

21 fichiers lisaient encore le fichier de thème sombre supprimé et mouraient
dessus. Cause d'environ 60 des échecs de tests — pas un couplage à la démo, une
migration laissée à moitié.

## 3. Les 47 écarts avec Figma — ce qu'ils sont vraiment

Le mot du rapport est **`behind`** : *en retard*. Pas « erreur ».

| Combien | Quoi | À faire |
|---|---|---|
| **21** | espacements, arrondi, bordures, tailles de police : ton code leur a donné un nom, ta maquette les écrit en dur | les créer dans Figma à la synchro |
| **24** | typographie Montserrat : styles de texte dans Figma, variables attendues côté code | choisir : les créer en variables, ou apprendre au comparateur à lire les styles |
| **1** | `color/nav-state` : variable **texte** valant « Transparent » dans Figma, couleur `#00000000` chez nous | trancher l'interprétation |
| **1** | le texte « Contactez-nous » est figé dans la maquette, réglable dans le code | un designer ajoute une propriété texte |

**⛔ Ne pas synchroniser vers Figma avant d'avoir prouvé la fidélité.** Le script
`figma-sync/02-button.js` **redessine** le set Bouton depuis le contrat, et notre
contrat a **abandonné les icônes flèches** (`cil:arrow-left/right`) : synchroniser
maintenant **les supprimerait du fichier des designers**.

## 5. Bloqué, hors de mon contrôle

**La comparaison pixel (`npm run extract:figma:visual`) ne peut pas tourner :** il
manque un jeton d'accès Figma. Chromium est installé, tout le reste est prêt.

Pour débloquer : Figma → Settings → Security → Personal access tokens
(portées `file_content:read` + `file_dev_resources:read`), puis à la racine du
dépôt :

```bash
echo 'FIGMA_TOKEN="figd_..."' > .env.local     # non suivi par git
```

C'est le 4ᵉ axe de fidélité. Les 3 autres sont prouvés.

## 6. Deux questions ouvertes, non résolues

**a) Le renommage de la collection Figma.** À 20h31 elle s'appelait « Variable
collection » / mode « Mode 1 ». À 22h30 : « Primitives » / « Value ». Or c'est
**exactement** ce que faisait le script de renommage proposé — **et refusé**. Le
propriétaire dit ne pas y avoir touché ; l'agent d'appoint a prouvé n'avoir passé
**aucun appel MCP**. L'historique de versions Figma trancherait, mais le jeton a
expiré. **Une action refusée a peut-être été exécutée : c'est plus grave que le
renommage lui-même.**

**b) Le déterminisme de la suite de tests n'a jamais été mesuré.** Le dépôt vend
le déterminisme, mais personne n'a jamais vérifié que la suite elle-même donne
deux fois le même résultat. Une tentative a échoué ce soir parce que nous
écrivions dans le projet pendant qu'elle tournait — chaque test recopie le
projet avant de démarrer, donc un projet qui bouge invalide la mesure.

   IA travaillant sur ton design system. Aujourd'hui elle reçoit la description
   d'un autre produit.
2. **Poser le jeton Figma** → le 4ᵉ axe de fidélité tombe.
3. **Réparer `plugin:check`** (5ᵉ liste en dur).
4. **Décider pour la typographie** : variables Figma, ou lecture des styles.
5. **Retirer les sélecteurs marque/thème** de l'en-tête.
6. **Synchroniser vers Figma** — *après* le point 2, et *jamais* sans avoir
   réglé la question des icônes flèches.
