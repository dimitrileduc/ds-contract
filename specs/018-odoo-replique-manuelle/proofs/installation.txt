BASE NEUVE, et voici pourquoi.
Un premier montage avait imprimé DEUX lignes ERROR imputables au module. Cause :
quand un manifeste ne porte pas de clé "description", Odoo se rabat sur le README
du module et le rend comme du reStructuredText. Notre README est en Markdown, donc
ses séparateurs de tableau (|---|---|) devenaient des substitutions RST non
définies. Rien à voir avec le module lui-même — mais SC-001 exige 0 erreur, et une
erreur imprimée reste une erreur imprimée.
Correctif : le manifeste porte désormais une "description" explicite, en RST plat.
Ce relevé-ci est fait sur une base RECRÉÉE (docker compose down -v puis remontée),
jamais sur une mise à jour par-dessus : SC-001 se lit sur une installation neuve,
ou ne se lit pas.
