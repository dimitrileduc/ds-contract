## Défaut d'instrument révélé par ce lot — et corrigé

Le mint de **284,4** a fait apparaître un **faux mismatch permanent** :

```
[figma-tokens MISMATCH] Primitives/size/reassurances/carte-cinq-cartes [Value]
  tokens/ says 284.4, Figma says 284.3999938964844
```

**Cause** : Figma stocke les variables `FLOAT` en **simple précision**. Écrire 284,4 rend
284.3999938964844. `parity/diff.ts` comparait les valeurs par leur **chaîne** — aucune
ré-exécution n'aurait pu éteindre ce finding : le différentiel réclamait la correction
d'une valeur déjà correcte.

**Correction** : `memeValeur()` compare les nombres via `Math.fround`, c'est-à-dire ce
que `tokens/` **veut dire** contre ce que Figma **peut stocker**. Ce n'est pas une
tolérance mais l'arithmétique exacte du stockage. La détection reste stricte :

| | |
|---|---|
| `fround(284,4)` vs `284.3999938964844` | **égales** ✓ |
| `fround(364)` vs `fround(363,5)` | différentes ✓ |
| `fround(284,4)` vs `fround(284,5)` | différentes ✓ |
| `fround(364)` vs `fround(999)` (sentinelle) | différentes ✓ |

**Pourquoi le défaut dormait** : tous les tokens décimaux de la fondation étaient des
`.5` (363.5, 339.5), que float32 tient exactement. `284,4` est **le premier** à ne pas
l'être.

**Précédent qui fait jurisprudence** : `parity/extract-figma.plugin.js` porte le même
correctif pour l'alpha des couleurs — *« the instrument inventing drift that does not
exist »*. Quand l'instrument invente une dérive, c'est l'instrument qu'on répare.
